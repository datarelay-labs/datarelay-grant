- `DEFER`: beyond accepted Grant 1.0 scope. Absence is intentional, not a missing feature.

Account & security is in the account menu. Do not create a Grant-specific copy of shared Foundation.
- **Approvals:** `web/src/request_inbox.tsx` has server-filtered needs/held/overdue/delegated views, advanced filters, bounded pagination and immutable action context. `web/src/request_evidence.tsx` already renders **current** reviewer seat votes separately from the timeline; previous UTC filter/reviewer source fixes are **complete** (#67 rev1–6).
- **Email decision split:** `grant/decision_links.py` generates a link at **`/api/v1/decision-intents/{token}`**, a read-only JSON preflight. `web/src/email_decision_portal.tsx`, `web/src/email_decision_adapter.ts`, `web/src/email_decision_flow.ts` implement standalone PIN/OTP/fresh-MFA/confirm presentations/contracts, but `web/src/app.tsx` does **not** import or mount the portal at the issued email link. - **Administration:** `web/src/administration.tsx` uses Foundation `AdministrationHub` (9 standard tasks and Grant Mail extension) with deliberate unsupported tasks labeled unavailable. **Two member capability contradictions** (`core.users` and `grant.smtp.test`) are reproduced in `web/tests/unit/administration-consumer-conformance.test.ts`; do not infer admin access is granted by merely displaying a task.
- **Policy/notifications:** `web/src/policies.tsx` provides list, grouped editor sections, Draft/Testing/Active/Disabled transitions, explicit confirmations, preview and version history. `web/src/notifications.tsx` provides templates/delivery; existing G3/G4 quorum and delegation are implemented. **Separate actual synthetic two-admin stale-editor/source observations** on roadmap #37 show Deny/MFA/integration verification-floor and notification-template saves can return 200/200 and silently overwrite trusted newer values. UI-only warnings do not replace server CAS.
- **Request details/audit:** `web/src/request_action_summary.tsx`, `request_evidence.tsx`, `audit_explorer.tsx` already separate exact action, current decision, audit, reported execution and transport accepted-only evidence. #48 rev4 source capped oversized audit comment projection with truthful total; **no real external Control/Stellar effect readback**.
